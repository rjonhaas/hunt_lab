# War Wagon workshop materials

[Repository home](../../README.md) · [Build a local lab](../../docs/local-setup.md)

Read a report, choose actions that reproduce its behaviors, run a controlled
Caldera operation and investigate its evidence in Kibana.

## Start here

1. [Training report: Discovery Before Collection](training-report.md)
2. [Participant guide](participant-guide.md)
3. [Hunt worksheet](hunt-worksheet.md)

**Hosted:** use the supplied Kibana login and follow the instructor's Caldera
demonstration. The instructor runs the shared operation and provides the target
hostname and evidence window.

**Local:** build and validate your lab before class, then author and run your own
operation. Both paths use the same report and two evidence-based challenges.

## After the walkthrough

The [reference builder](scenario/README.md) provides a practice implementation
and evidence verifier. It is a fallback or follow-up reference; start by working
from the report. Its public practice markers are not the conference flags.

The [additional lab reference](../../docs/lab-reference.md) covers scenarios and
tools outside this exercise. Delivery notes and planning material are indexed
under [instructor materials](instructor/README.md).
